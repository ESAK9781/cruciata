# Realism visual branch

This branch changes presentation while retaining the main game's rules, unit statistics, controls, saves, enemy economy, and capture mechanics. The playable comparison is hosted at https://esak9781.github.io/cruciata/realism/.

## Assets

Generated with the built-in `image_gen` tool using the imagegen skill. These are illustrative game assets, not documentary evidence of historical buildings or uniforms. The renderer uses four atlas PNGs: `assets/realism/materials.png`, `assets/realism/buildings-overhead.png`, `assets/realism/units.png`, and `assets/realism/resources.png`. Transparent sprite cells are cropped at runtime; faction colors are prepared once. The initial perspective building study is retained outside the published project in the workspace artifacts folder.

Terrain and roads use material patterns. Units, buildings, resource patches, trees, boats, portraits, and resource icons use the atlases. Connected walls, rock rims, construction, tools, deployment, attacks, fire, and water retain procedural animations with muted materials. The interface uses physical stone/timber textures and system fonts. The impassable rock clusters keep their continuous black interiors as requested; no mountain renderer exists.
