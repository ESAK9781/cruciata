Playing with a friend

  • Both of you install the same version (always the latest) and open LAN multiplayer.
  • One chooses Host a game. The other sees it appear in the list and presses Join.
  • That is all: no addresses, ports or router settings. Allow the game through the firewall if your system asks once.

Downloads come from the project's GitHub releases. Builds are not code-signed, so macOS may ask you to right-click → Open the first time, and Windows may show a SmartScreen notice. The game stays fully offline.
